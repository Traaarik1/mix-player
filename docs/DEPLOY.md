# Как поставить Mix на iPhone

Mix живёт на бесплатном хостинге GitHub Pages, а на iPhone добавляется иконкой на экран «Домой». Платить не нужно ни за что. Первый раз уйдёт минут 15.

## Что будет видно всем

| Публично, в открытом доступе | Только на твоём устройстве |
|---|---|
| Код плеера и всё остальное из папки `mix-player` | Музыка и обложки |
| Твой логин GitHub (он будет в адресе сайта) | Вход в Telegram и ключи api_id, api_hash |
| | Ключ AcoustID, плейлисты, лайки, настройки |

Если кто-то откроет твою ссылку, он увидит пустой плеер. Твоей музыки и твоего Telegram у него не будет.

В папке лежат `SPEC.md` и `PLAN.md`, они тоже станут публичными, а в них есть твоё имя и планы по проекту. Если не хочешь их показывать, до публикации допиши эти два имени отдельными строками в файл `.gitignore`.

Чтобы плеер работал, он обращается к чужим бесплатным сервисам: Telegram, iTunes (обложки, названия), LRCLIB (тексты), AcoustID (распознавание). Им уходят названия треков или звуковой отпечаток, но не сами файлы.

## 1. Опубликовать сайт

Нужен бесплатный аккаунт на [github.com](https://github.com). Бесплатный хостинг работает только с открытым репозиторием, поэтому код будет публичным.

1. Открой **GitHub Desktop** и войди в аккаунт: File → Options → Accounts.
2. Нажми File → **Add local repository** и выбери папку `Documents\Apps\mix-player`. Именно её, а не всю папку `Apps`.
3. Программа скажет, что это ещё не репозиторий. Нажми ссылку **create a repository**. Название оставь `mix-player`, галочку про README не ставь, нажми **Create repository**.
4. Нажми **Publish repository**. **Сними галочку «Keep this code private»** и снова нажми Publish repository.
5. На сайте GitHub открой свой репозиторий `mix-player` → **Settings** → слева **Pages**.
6. В разделе Build and deployment выбери Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**. Нажми **Save**.
7. Подожди пару минут и обнови страницу. Вверху появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/mix-player/`. Открой его на компьютере и проверь, что плеер запускается.

## 2. Поставить на iPhone

Лучше всего iOS 17.5 или новее: в более старых версиях звук в фоне работает хуже или обрывается.

1. Открой адрес сайта именно в **Safari**.
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»**. Если есть переключатель «Открывать как веб-приложение», он должен быть включён. Нажми **«Добавить»**.
4. Запусти Mix **с этой иконки** и только там подключай Telegram.

**Важно.** У иконки своё отдельное хранилище, оно не связано с Safari. То, что скачано или настроено во вкладке Safari, в иконке не появится.

После первого запуска открой Mix с иконкой один раз при включённом интернете: так он сохранит себя для работы без сети.

## 3. Как приходят обновления

1. Когда в код внесены изменения, выполни в папке `mix-player`:
   ```
   powershell -ExecutionPolicy Bypass -File deploy.ps1
   ```
   Команда запишет новую версию. Ничего никуда она не отправляет.
2. В GitHub Desktop напиши короткое описание, нажми **Commit to main**, затем **Push origin**.
3. Через пару минут сайт обновится. На iPhone новая версия появится при следующем запуске Mix при включённом интернете. Иногда нужно закрыть его смахиванием и открыть ещё раз.

Музыка, вход и плейлисты при обновлении остаются на месте.

## Что может удалить данные

- **Удаление иконки Mix с экрана «Домой»** удаляет всю скачанную музыку и вход в Telegram. Их придётся скачивать и подключать заново.
- **Нехватка места на iPhone.** Приложение может занять до 60% диска, но при острой нехватке места iOS вправе очистить данные. Музыка при этом не пропадёт из канала, её можно скачать ещё раз.
- Резервных копий скачанной музыки в iCloud нет.

## Что проверить на iPhone

Без настоящего телефона это проверить нельзя, поэтому пройди список после установки:

1. Запуск трека первым нажатием на него: звук есть сразу.
2. Звук при включённом беззвучном режиме.
3. Заблокируй экран: музыка играет, на экране блокировки видны название и обложка, работают пауза и «дальше».
4. Переход на следующий трек при заблокированном экране. Дождись двух переходов подряд.
5. Позвони себе с другого телефона или включи Siri, затем заверши: музыка продолжается или возвращается после нажатия на экран.
6. Поставь на паузу, заблокируй экран, подожди минуту и нажми «играть» с экрана блокировки.
7. Режим полёта: Mix открывается с иконки, скачанные треки играют.
8. Длинный трек (час и больше): плеер не перезагружается сам.

Если на шаге 3 или 4 звук обрывается, открой в Safari адрес сайта с припиской `?route=stream` и повтори проверку там: это другой способ вывода звука. Напиши, что получилось, и Mix настроят под твоё устройство.
