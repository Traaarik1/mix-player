# Синхронизация и распознавание через микрофон

## Синхронизация между ПК и iPhone

Лайки, плейлисты, история, исправленные названия, переход, эквалайзер и отзывы волны хранятся одним файлом `mix-sync.json` в твоём «Избранном» Telegram. Сервера нет, платить не за что.

**Что нужно сделать:** ничего, достаточно войти в Telegram на обоих устройствах.

- Файл лежит в «Избранном». Удалять его не надо; если удалишь, плеер создаст новый из своих данных.
- В файл не попадают ключи `api_id`/`api_hash`, сессия Telegram, ключ AcoustID и токен AudD.
- Плеер трогает только этот файл. Канал с музыкой и другие сообщения он не читает и не меняет.
- Правки без интернета сохраняются и уезжают при появлении сети. Снятый лайк и удалённый плейлист обратно не вернутся.
- Если на двух устройствах поменять одно и то же, останется более поздняя правка. Но лайки и треки плейлиста объединяются, а не перезаписывают друг друга.
- Удаление плейлиста окончательное: треки, добавленные в него на другом устройстве, пропадут вместе с ним.
- Сами аудиофайлы и громкость не синхронизируются. Громкость у каждого устройства своя.

## Распознавание через микрофон

Звук записывается 12 секунд и уходит в сервис [AudD](https://audd.io/). Обложка и 30-секундное превью берутся из iTunes.

**Честно про бесплатность.** Полностью бесплатного сервиса без ограничений, который работает прямо из браузера, не нашлось.

| Вариант | Сколько бесплатно | Регистрация |
|---|---|---|
| AudD без токена | около 10 запросов в день с одного IP-адреса (официально не опубликовано) | не нужна |
| AudD с токеном | 300 запросов один раз; по сторонним отзывам ещё и не дольше 14 дней. Дальше платно, $5 в месяц | нужна, без карты |

**Что нужно сделать:** сначала ничего, всё работает без токена. Если запросы кончились, а до завтра ждать не хочется:

1. Зарегистрируйся на https://dashboard.audd.io/signup (карта не нужна).
2. Скопируй API-токен из личного кабинета.
3. Вставь его в настройках Mix. Токен хранится только на этом устройстве и в синхронизацию не попадает.

**На iPhone есть запасной способ без лимитов:** встроенное «Распознавание музыки» (Shazam) в Пункте управления. Плеер с ним никак не связан.

**Что важно знать:**

- Запись уходит на серверы AudD. Микрофон включён только на время записи.
- Перед записью плеер встаёт на паузу, иначе сервис услышит его самого.
- Браузер спросит разрешение на микрофон. Микрофон работает только по https или на localhost.

## Почему выбран AudD

Проверено 05.11.2026 запросами с заголовком `Origin`.

| Сервис | Из браузера (CORS) | Бесплатно | Вывод |
|---|---|---|---|
| AudD | да, `Access-Control-Allow-Origin: *` | см. таблицу выше | выбран |
| ACRCloud | да, `*` | только пробный период 14 дней, нужны регистрация и подпись запроса секретом | через две недели станет платным |
| AudioTag | **нет**, ответ без заголовков CORS, `OPTIONS` даёт 405 | 3 часа аудио в месяц, нужна регистрация | самый щедрый лимит, но из браузера не вызвать; нужен свой прокси, то есть сервер |
| AcoustID + Chromaprint | да | бесплатно, нужен ключ | для микрофона не подходит: ищет целые треки, короткие отрывки автор сервиса поддерживать не планирует. Остаётся для проверки файлов |
| Закрытые адреса Shazam | | | не используем: это обратная разработка, может сломаться в любой день |
